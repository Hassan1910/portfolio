# Portfolio

Personal portfolio site for **Hassan Adan** — projects, skills, and contact.

**Live:** [https://portfolio-omega-orpin-13.vercel.app](https://portfolio-omega-orpin-13.vercel.app)

## Stack

- TypeScript
- React / Vite
- Tailwind CSS

## Getting started

```bash
npm install
npm run dev
```

Open the local URL printed by Vite (usually `http://localhost:5173`).

## Scripts

| Command | Description |
|---------|-------------|
| `npm run dev` | Start local development server |
| `npm run build` | Production build |
| `npm run preview` | Preview production build |
